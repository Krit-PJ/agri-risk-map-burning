# Same Period Prior-Year Comparison Update

ปรับและยืนยันพฤติกรรมตาราง "เปรียบเทียบ Hotspot" ให้ใช้ช่วงเดือน/ปีเดียวกันย้อนหลัง 1 ปีตามช่วงที่ผู้ใช้เลือก

## หลักการ

- ช่วงปัจจุบัน = ตั้งแต่ เดือน/ปี ถึง เดือน/ปี ที่ผู้ใช้เลือกและกด "แสดงข้อมูล"
- ช่วงเปรียบเทียบ = ช่วงเดียวกันย้อนหลัง 12 เดือน
- ตัวอย่าง:
  - ม.ค. 2569 – พ.ค. 2569 เทียบกับ ม.ค. 2568 – พ.ค. 2568
  - ต.ค. 2568 – พ.ค. 2569 เทียบกับ ต.ค. 2567 – พ.ค. 2568
  - เม.ย. 2569 เทียบกับ เม.ย. 2568

## ไฟล์หลักที่เกี่ยวข้อง

- js/app.js: ตัวเลือกช่วงเดือน/ปีและปุ่มแสดงข้อมูล
- js/map.js: กรองจุด HS ตามช่วงเดือน/ปีบนแผนที่
- js/dashboard.js: ตารางเปรียบเทียบ Hotspot ช่วงที่เลือกกับช่วงเดียวกันปีก่อน
- data/hotspot/*.geojson: ข้อมูล HS ทุกปีที่ผ่านกติกา Province=กำแพงเพชร, LandType=พื้นที่เกษตร, PlantType ตามกลุ่มที่กำหนด

## หมายเหตุข้อมูล

ระบบจะแสดงเฉพาะข้อมูลที่มีอยู่จริงในไฟล์ GeoJSON ของแต่ละปี หากปีใดไม่มีข้อมูลบางเดือน เช่น ต.ค.–ธ.ค. ของปีเก่า จำนวนในช่วงนั้นจะเป็น 0 ตามข้อมูลที่มี ไม่ใช่การประมาณค่า
