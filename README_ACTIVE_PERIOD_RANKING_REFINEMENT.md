# Active Period and Ranking Refinement

ปรับปรุงตามข้อเสนอ 18 ก.ค. 2569

## รายการปรับปรุง

1. ตัวเลือกช่วงข้อมูลจุดความร้อนสะสมจะยังไม่เปลี่ยนผลลัพธ์ทันทีเมื่อเปลี่ยนเดือน/ปี แต่จะ active เฉพาะเมื่อกดปุ่ม **แสดงข้อมูล**
2. คอลัมน์เพิ่ม/ลดในตารางเปรียบเทียบ Hotspot แสดงร้อยละเป็นจำนวนเต็ม เช่น `+900%` แทน `+900.0%`
3. ตาราง/Card ทุกอำเภอ (Hotspot สูงสุด) แสดงครบ 11 อำเภอ แม้บางอำเภอมีค่า 0 ในช่วงที่เลือก
