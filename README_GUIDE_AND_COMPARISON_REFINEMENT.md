# Guide and Hotspot Comparison Refinement

ปรับปรุงตามข้อเสนอแนะการทดลองใช้งาน:

1. ปรับข้อความช่วงคะแนนระดับความเสี่ยงให้แสดงทศนิยม 1 ตำแหน่ง: 0-24.9, 25-49.9, 50-74.9 และ 75-100 คะแนน
2. เพิ่มการควบคุมการแสดงปุ่มคู่มือการประเมินความเสี่ยงในโหมด Admin
   - ผู้ดูแลสามารถเปิด/ปิดปุ่มคู่มือได้
   - ปุ่มคู่มือเปิดไปยัง Google Drive folder ไม่เปิด PDF local โดยตรง
   - สถานะการเปิด/ปิดเก็บใน localStorage
3. ปรับหัวตารางเปรียบเทียบ Hotspot ให้ชื่อหัวข้อและข้อความช่วงเวลาอยู่คนละบรรทัด
4. ปรับคอลัมน์เพิ่ม/ลด กรณีค่าปีก่อน = 0 และปีปัจจุบัน > 0 จากคำว่า “ใหม่” เป็น +N00.0% เช่น 0 → 7 จุด แสดง +700.0%

หมายเหตุ: การแสดง +N00.0% ในกรณีฐานเดิมเป็น 0 เป็นนิยามเชิงปฏิบัติการของระบบ เพื่อให้เห็นขนาดการเพิ่มขึ้นจากจำนวนจุดใหม่ โดยไม่ใช้คำว่า “ใหม่” ตามคำขอผู้ใช้งาน
