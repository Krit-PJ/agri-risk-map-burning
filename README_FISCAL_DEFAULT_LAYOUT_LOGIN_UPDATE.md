1. ค่าเริ่มต้นของช่วงข้อมูลจุดความร้อนสะสมเปลี่ยนเป็น ตุลาคมของปีก่อนหน้า ถึงเดือนล่าสุดของข้อมูลที่มีอยู่จริงในระบบ
