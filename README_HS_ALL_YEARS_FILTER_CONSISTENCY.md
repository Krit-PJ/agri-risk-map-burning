# HS Filter Consistency Update

อัปเดตนี้ปรับข้อมูล Hotspot ปี 2566, 2567, 2568 ให้ใช้เงื่อนไขเดียวกับปี 2569

## กติกากรองมาตรฐาน

1. ใช้จังหวัดจากคอลัมน์ `Province` หรือ `จังหวัด` และเลือกเฉพาะ `กำแพงเพชร`
2. ใช้ลำดับขอบเขตจากข้อมูลต้นทาง: `Province → Amphoe → Tambon → BaanN`
3. เลือกเฉพาะ `LandType = พื้นที่เกษตร` หรือคอลัมน์ไทย `พื้นที่รับผิดชอบ = พื้นที่เกษตร`
4. ใช้ `PlantType` หรือคอลัมน์ไทย `การใช้ที่ดิน` ในการคำนวณ/จัดกลุ่ม
5. กลุ่ม PlantType ที่อนุญาต:
   - นาข้าว
   - อ้อย
   - ข้าวโพดและไร่หมุนเวียน
   - เกษตรอื่น ๆ
   - พื้นที่ป่า
   - อื่น ๆ

## จำนวนหลังกรองใหม่

| ปีชุดข้อมูล | จำนวน HS หลังกรอง | ช่วงข้อมูล |
|---|---:|---|
| 2566 | 384 | ม.ค.–พ.ค. 2566 |
| 2567 | 341 | ม.ค.–พ.ค. 2567 |
| 2568 | 273 | ม.ค.–พ.ค. 2568 |
| 2569 | 585 | ต.ค. 2568–พ.ค. 2569 |

หมายเหตุ: ตัวเลขเดิม 2566=916, 2567=682, 2568=547 เป็นข้อมูลจากชั้นข้อมูลเดิมที่ไม่ได้ยืนยันเงื่อนไข `LandType=พื้นที่เกษตร` เหมือนกันทุกปี จึงถูกปรับให้เป็นชุดมาตรฐานเดียวกัน
