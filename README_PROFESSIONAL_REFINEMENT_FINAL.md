# Professional Refinement Final Update

รายการปรับปรุง

1. เปลี่ยนปุ่มคู่มือเป็น “คู่มือระบบประเมินความเสี่ยง” และเชื่อมโยงไปยัง Google Drive folder ตาม URL ที่กำหนด
2. ปรับสีคอลัมน์เพิ่ม/ลดในตารางเปรียบเทียบ Hotspot: ค่าบวกเป็น Red Highlight; ค่า 0 หรือค่าลบเป็น Green Highlight
3. นำ Card “Hotspot รายปี - จังหวัดกำแพงเพชร” ออกจาก Dashboard เพื่อลดความซ้ำซ้อน
4. ปรับ Card “Top 10 อำเภอ (Hotspot สูงสุด)” เป็นการแสดงทุกพื้นที่ในระดับปัจจุบัน และตัดคอลัมน์จังหวัดออก

หมายเหตุ: โครงสร้างข้อมูล Hotspot, เงื่อนไขการกรอง Province/LandType/PlantType, ช่วงเดือน/ปี และการเทียบช่วงเดียวกันย้อนหลัง 1 ปี ยังคงตามเวอร์ชันก่อนหน้า
