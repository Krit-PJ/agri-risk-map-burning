# การปรับข้อมูล HS ตาม hsPlant2026 (3 กันยายน 2569)

## ข้อสรุป

ปรับชุดข้อมูล Hotspot ปี 2569 และระบบนำเข้า Excel ให้ใช้เงื่อนไขเดียวกับรายงาน `hsPlant2026`:

- `Province = กำแพงเพชร`
- `LandType = พื้นที่เกษตร`
- `PlantType` รับเฉพาะ `นาข้าว`, `อ้อย`, `เกษตรอื่น ๆ`, `อื่น ๆ`

`hsPlant2026` เป็น Pivot Table สำหรับตรวจยอด ส่วนข้อมูลรายจุดและพิกัดนำมาจาก `hsAll` ภายใน workbook เดียวกัน ระบบจะบันทึกผลได้ต่อเมื่อยอดรวมและยอดแยก PlantType จาก `hsAll` ตรงกับ `hsPlant2026` ทุกค่า

## ความแตกต่างจากชุดก่อนหน้า

ชุดก่อนหน้ามี 585 จุด ส่วนชุดนี้มี 593 จุด เพิ่ม 8 จุด (+1.37%) โดยนาข้าวเพิ่มจาก 442 เป็น 448 จุด และอ้อยเพิ่มจาก 82 เป็น 84 จุด ขณะที่เกษตรอื่น ๆ และอื่น ๆ ไม่เปลี่ยนแปลง

ข้อมูลเพิ่มเติม 8 จุดอยู่ในเดือนกรกฎาคม 2569 จำนวน 3 จุด และเดือนสิงหาคม 2569 จำนวน 5 จุด ส่งผลให้เดือนล่าสุดของระบบเปลี่ยนจากพฤษภาคม 2569 เป็นสิงหาคม 2569

## ส่วนที่ปรับในระบบ

1. ปรับข้อมูล `hotspot_2569.geojson` และไฟล์ QA/สรุปรายวัน รายเดือน รายปี
2. จำกัดตัวกรอง PlantType ในหน้าระบบให้แสดงเฉพาะ 4 กลุ่มที่อนุญาต
3. ปรับ Admin Excel Import ให้รองรับคอลัมน์วันที่ทั้ง `Date` และ `YYYY-MM-DD`
4. ป้องกันค่าว่างใน PlantType ถูกแปลงเป็น `อื่น ๆ` โดยอัตโนมัติ
5. อ่านยอดอ้างอิงจาก `hsPlant2026` และแจ้งผลว่าตรงหรือไม่หลังนำเข้า
6. เพิ่มเครื่องมือ `tools/process_hotspot_hsplant2026.py` สำหรับสร้างข้อมูลซ้ำแบบตรวจสอบย้อนกลับได้

## วิธีสร้างข้อมูลซ้ำ

ติดตั้ง Python และ `openpyxl` แล้วเรียกจาก root ของระบบ:

```text
python tools/process_hotspot_hsplant2026.py --input "2026-9-3 HS2026.xlsx" --output-dir data/hotspot --dataset-year 2569
```

หากผลจาก `hsAll` ไม่ตรงกับ `hsPlant2026` เครื่องมือจะหยุดและไม่เขียนทับไฟล์ผลลัพธ์
