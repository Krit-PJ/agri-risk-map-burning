# HS Filter Validation Update

อัปเดตนี้ปรับการกรองและการนับจุดความร้อนให้ตรงกับลำดับข้อมูลต้นทางจาก Excel:

1. ใช้คอลัมน์ `Province` เป็นตัวกรองจังหวัดหลัก และเลือกเฉพาะ `กำแพงเพชร`
2. ใช้ลำดับพื้นที่จากตารางต้นทาง: `Province → Amphoe → Tambon → BaanN`
3. เลือกเฉพาะ `LandType = พื้นที่เกษตร`
4. ใช้ `PlantType` เป็นชนิดข้อมูลหลักในการคำนวณและกรอง ได้แก่
   - นาข้าว
   - อ้อย
   - ข้าวโพดและไร่หมุนเวียน
   - เกษตรอื่น ๆ
   - พื้นที่ป่า
   - อื่น ๆ
5. ไม่ใช้ spatial join ไปเขียนทับชื่ออำเภอ/ตำบลจากไฟล์ Excel อีกต่อไป ยกเว้นกรณีชื่อพื้นที่ในตารางต้นทางว่าง
